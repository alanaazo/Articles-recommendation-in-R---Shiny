# Articles-recommendation-in-R---Shiny

This is an educational project that I did together with other HSE students. Its purpose is to recommend scientific articles from the available database to the user based on such characteristics as articles they like, preferred length of the article, etc. The main file with the code is 22-final-report-copy_2.rmd. The application code is app_shiny_articles.r.
